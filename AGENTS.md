# Инструкции для агентов

## Запрет на сборку

Не запускать сборку проекта и Docker-образов. Запрет распространяется на прямые команды сборки и на сборку, выполняемую косвенно при запуске приложения, тестов, скриптов или Docker Compose.

Для проверки изменений использовать чтение исходников, конфигурации и анализ diff без сборки. В отчёте указывать, какие проверки не выполнялись из-за этого запрета.
